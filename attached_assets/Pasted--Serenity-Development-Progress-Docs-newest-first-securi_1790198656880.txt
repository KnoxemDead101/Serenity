## Decisions (9/23)
- A Business link requires classification Business: it defaults to Business when blank, and an explicit mismatch is rejected (422).
- "Shared / All Children" is its own Dependent: no percentages.
- Deactivated **accounts** still count toward net worth but reject new transactions. Deactivated bills, debts, investments and income profiles leave the totals.
- Export is backup-only; there is no restore yet.
- Production: Replit Publish copies structure only; production never runs Alembic. Run `scripts/prepublish_check.sh` before every publish.
- Ownership: `owner_id` is required on every record, with no default and no test-user bypass. Tests sign in via `dependency_overrides`.
- Income Profiles are plans, not transactions. Monthly = yearly ÷ 12 (never weekly × 4). Variable income is never projected. There is no tax engine: net is the user's own take-home figure.
- Theme: dark near-black, white text, gold primary, restrained red accent, the system-ui font.
